# EASE-Delta documentation

## Using it

| Page | Read it when |
|---|---|
| [Getting started](getting-started.md) | you want a task tracked in the next ten minutes |
| [Concepts](concepts.md) | you want to know what *requirement*, *record*, *reading*, *ready* and *worth asking* mean exactly |
| [Python API](python-api.md) | you are writing code against `EvidenceReader` and `Tracker` |
| [HTTP API](http-api.md) | you are calling the service from another program |
| [Reader guide](reader.md) | you only need claim-against-passage reading, in `transformers`, sentence-transformers, ONNX or a browser |
| [Deployment](DEPLOYMENT.md) | you are running it for a team, or for several teams behind keys |
| [FAQ](faq.md) | you have a specific question: accuracy, privacy, licences, hardware, languages |
| [Results at a glance](results-summary.md) | you want the measured numbers in one table |

Runnable examples live in [`examples/`](../examples): [`quickstart.py`](../examples/quickstart.py) and the
[Colab notebook](https://colab.research.google.com/github/jithinsaireddy/ease-delta/blob/main/examples/try_ease_delta.ipynb).
