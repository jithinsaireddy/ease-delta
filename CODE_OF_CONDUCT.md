# Code of conduct

This project is a place to build something useful and to tell the truth about how well it works.

- Be kind and assume good intent. Criticise ideas and code, not people.
- Be precise. Claims about results need evidence; "it seems better" is a starting point, not a conclusion.
- Respect privacy. Never post someone's real correspondence without consent; anonymise examples.
- No harassment, discrimination, or personal attacks, in any space connected to the project.

Report a problem to the maintainer at the address on the maintainer's GitHub profile, or by a private security
advisory on the repository. Reports are handled confidentially. The maintainer may remove content and block
participants who do not follow this code.
